# Yarema

Голосовий асистент для гуманоїда.

## Актуальна версія: `v3(2)/`

Це єдина версія, з якою реально працює команда: підключена до живого n8n-воркфлоу
(`n8n-agents/calendar-agent-ecosystem`), протестована голосом, переведена на `uv` (Python 3.12) —
у копії саме тут, в репозиторії Григорій. Уся подальша розробка йде тут.

## Legacy: `v1` / `v2` / `v3`

Три попередні паралельні версії (гібридний STT/TTS-пайплайн → перехід на OpenAI Realtime API →
перша інтеграція з n8n) заморожені й не розробляються. Рішення зафіксовано 19.08.2026 (картка
"Уніфікація агента" плану стабілізації).

Їхній код навмисно **не скопійований у цей репозиторій** — Григорій містить лише актуальну версію.
За потреби звернутись до старого коду для довідки, він лишається на гілці `Yarema` (оригінальний
репозиторій), у `yarema/v1/`, `yarema/v2/`, `yarema/v3/` — саме там, де й був.

Секрети (`.env`) не входять до репозиторію — створіть `.env` локально за зразком змінних, які
використовує `config.py` цієї версії.
