# Assistant-agent — голосовий асистент Humanoid Company

Голосовий асистент, з яким можна говорити як з людиною. Він бачить ваш Google Календар, пошту й нотатки, вміє шукати в інтернеті й виконує прохання голосом: «що в мене завтра?», «запиши зустріч з Олегом на п'ятницю о 15:00», «чи є нові листи від бухгалтерії?», «додай у нотатки ідею для демо».

Працює у двох варіантах: **десктопна програма** з wake word і **веб-версія** для команди, яку достатньо відкрити в браузері.

> 🎙️ **Спробуйте просто зараз:** [voice-agents-web-three.vercel.app](https://voice-agents-web-three.vercel.app/). Нічого встановлювати не треба, достатньо браузера й мікрофона.

## Що вміє

- **Природна розмова голосом.** В основі — OpenAI GPT-Live (`VOICE_ENGINE=live`), запасний варіант — OpenAI Realtime (`VOICE_ENGINE=realtime`).
- **Розумне перебивання.** Агент зупиняється, лише коли ви справді хочете взяти слово (стоп-слово або початок вашої репліки), і не реагує на «угу», «ага», фоновий шум чи власне ехо.
- **Google Календар.** Переглядає, створює й змінює події.
- **Gmail.** Читає й шукає листи, допомагає з відповідями.
- **Нотатки** (Google Drive + Docs): додати, прочитати, знайти.
- **Вебпошук** через Tavily (необов'язково).
- **Налаштування голосу, мови та імені асистента.**

Кожен користувач входить своїм Google-акаунтом. Сторонні сервіси на кшталт n8n не потрібні: агент звертається до Google API напряму.

## Як влаштовано

### Веб-версія (для команди)

```
Браузер (web/, Vercel) ──WebRTC: мікрофон і звук──► OpenAI GPT-Live
        │                                                ▲
        │ SDP-оффер, вхід у Google                       │ sideband (інструменти)
        ▼                                                │
Бекенд (server/, Render) ────────────────────────────────┘
   └─ Google Calendar / Gmail / нотатки, вебпошук
```

- Звук іде напряму між браузером і OpenAI, тому затримка мінімальна, а ехо придушує сам браузер.
- Ключ OpenAI зберігається лише на бекенді.
- Інструменти (Google, вебпошук) виконує бекенд через sideband-з'єднання з тією ж сесією.
- Дані входу в Google зберігаються лише в пам'яті сервера і зникають після його перезапуску.

### Десктопна версія

Wake word «привіт» → голосова сесія → локальний Agent Router → Google API. Мікрофон, VAD і захист від ехо локальні, токени Google зберігаються в Windows Credential Manager.

| | Десктоп (`main.py`) | Веб |
|---|---|---|
| Запуск розмови | wake word «привіт» | кнопка «Почати розмову» |
| Звук | локальний мікрофон, VAD, власний захист від ехо | WebRTC у браузері |
| Вхід у Google | OAuth Desktop-клієнт, вікно на тому ж ПК | OAuth Web-клієнт, редірект на бекенд |
| Токени | Windows Credential Manager | пам'ять сервера |

## Структура проєкту

| Шлях | Призначення |
|---|---|
| `main.py`, `assistant.py` | десктопний застосунок: життєвий цикл (сон ↔ сесія), пам'ять, спільні хелпери інструментів |
| `voice/` | драйвери голосових рушіїв (`live_driver.py`, `realtime_driver.py`), логіка перебивання, налаштування голосу й мови |
| `router/agent_router.py` | локальний роутер: вільний текст → інтенти |
| `tools/` | схеми інструментів для Live і Realtime, міст до роутера, вебпошук |
| `server/` | бекенд веб-версії (FastAPI) |
| `web/` | фронтенд веб-версії (статичні файли) |
| `render.yaml`, `requirements-server.txt` | деплой бекенду на Render |
| `DEPLOY.md` | покрокова інструкція з розгортання веб-версії |

## Швидкий старт

### Спробувати веб-версію

Відкрийте [voice-agents-web-three.vercel.app](https://voice-agents-web-three.vercel.app/) → «Почати розмову» → дозвольте мікрофон → говоріть. Щоб агент бачив календар і пошту, натисніть «Підключити Google». Якщо Google попередить, що застосунок не перевірено: «Додатково» → «Перейти до …».

### Розгорнути веб-версію

Коротко: OAuth-клієнт **Web application** у Google Cloud → бекенд на Render (Blueprint з `render.yaml`) → фронтенд на Vercel (Root Directory = `web`). Деталі — у [DEPLOY.md](DEPLOY.md).

Змінні середовища бекенду:

| Змінна | Опис |
|---|---|
| `OPENAI_API_KEY` | ключ OpenAI |
| `PUBLIC_BACKEND_URL` | публічна адреса бекенду, без `/` у кінці |
| `FRONTEND_ORIGINS` | адреса(и) фронтенду через кому |
| `GOOGLE_OAUTH_WEB_CLIENT_ID` / `GOOGLE_OAUTH_WEB_CLIENT_SECRET` | дані Web OAuth-клієнта |
| `ACCESS_CODE` | пароль на сторінку; порожнє значення = доступ для всіх, у кого є посилання |
| `WEB_SEARCH_API_KEY` | ключ Tavily (необов'язково) |
| `GOOGLE_CALENDAR_TIMEZONE` | часовий пояс, за замовчуванням `Europe/Kyiv` |

### Локальний запуск веб-версії

```bash
uv sync --group server
# .env: OPENAI_API_KEY, PUBLIC_BACKEND_URL=http://localhost:8000,
#       GOOGLE_OAUTH_WEB_CLIENT_ID/SECRET (redirect http://localhost:8000/auth/google/callback)
.venv/Scripts/python.exe -m uvicorn server.app:app --port 8000

# фронтенд
python -m http.server 5173 -d web
# відкрити http://localhost:5173/?backend=http://localhost:8000
```

## Обмеження

- Поки застосунок не пройшов верифікацію Google, під час входу з'являється попередження, а кількість користувачів обмежена сотнею.
- На безкоштовному плані Render сервер засинає після ~15 хвилин без запитів. Перше відкриття триває до хвилини, і після цього Google треба підключити знову.
- Голосові сесії оплачуються з балансу OpenAI, тому задайте ліміт витрат у налаштуваннях OpenAI.
